# Семейное расписание

Готовый статический фронтенд для GitHub Pages + Supabase.

Профили:
- Мама
- Папа
- Влада
- Никита

Начальный пароль у всех: `1234`.

## Что уже работает

- отдельный вход в каждый профиль;
- сессия сохраняется в `localStorage`, поэтому повторный вход на том же устройстве не нужен;
- редактирование интервалов занятий;
- защита от пересечения занятий;
- 07:00–22:00: пустые промежутки автоматически показываются как «Свободное время»;
- 22:00–07:00: автоматически показывается «Сон»;
- данные хранятся централизованно в Supabase;
- фронтенд не использует внешние JS/CSS CDN;
- подходит для GitHub Pages и добавления на экран «Домой» iPhone.

## Подключение Supabase

1. Создайте проект Supabase.
2. В SQL Editor выполните файл `supabase.sql`.
3. В Project Settings → API скопируйте:
   - Project URL
   - anon/public key
4. Вставьте их в `config.js`.

## GitHub Pages

Загрузите файлы в репозиторий, затем:
Settings → Pages → Deploy from a branch → `main` / root.

После публикации откройте адрес `https://<username>.github.io/<repo>/`.

## Важно

`anonKey` не является секретным ключом и может находиться во фронтенде.
Таблицы закрыты от прямого доступа; сайт работает через три `SECURITY DEFINER` RPC-функции.
