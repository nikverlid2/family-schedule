Что загрузить в GitHub
========================

Заменить:
- index.html
- app.js
- styles.css

Добавить новый файл:
- service-worker.js

config.js и manifest.webmanifest НЕ менять.

После Commit changes дождитесь обновления GitHub Pages.
На iPhone:
1. Откройте сайт в Safari.
2. Поделиться -> На экран «Домой».
3. Откройте приложение с домашнего экрана.
4. Войдите.
5. Нажмите «Уведомления» и разрешите их.

Цвета:
- красный
- оранжевый
- синий
Выбираются тремя маленькими квадратами в режиме Правка.
